# SNS動画ラフ生成ツール

投稿の目的と伝えたい一言を入れると、**Canva AI が縦型（9:16）・3〜4ページの絵コンテを方向性違いで最大3案**作り、Canvaで動画にするための**動画化メモ**（ページごとの秒数・アニメーション・切り替え・素材の検索キーワード・BGMの雰囲気）を添える社内ツールです。

完成品ではなく、企画の話し合いと校正のための叩き台を作ります。動画にする作業は、メモを見ながら人がCanvaで行います。

- 外部ライブラリは使っていません。Node.js だけで動きます（ビルド不要）。
- データはこのフォルダの `data/` に保存されます（SQLite）。

---

## 1. 準備するもの

| もの | 入手先 | メモ |
| --- | --- | --- |
| Node.js 22.13 以上 | https://nodejs.org/ （LTS 版） | インストール後、ターミナルで `node -v` が `v22.13` 以上ならOK |
| Claude API のキー | https://console.anthropic.com/ | 構成案と動画化メモを作るのに使います（従量課金） |
| Canva アカウント | 団体の NPO プログラムのチーム | 絵コンテの生成に Canva の AI クレジットを使います（1案あたり約2%） |

## 2. セットアップ（最初の1回だけ）

```bash
# このフォルダに移動して
cp .env.example .env        # Windows の場合: copy .env.example .env
```

`.env` をメモ帳などで開き、`ANTHROPIC_API_KEY=` の後ろに Claude API のキーを貼り付けて保存します。

次に、Canva につながるか確かめます。

```bash
npm run check-canva
```

「✔ クライアント登録ができました」と出ればOKです。✘ が出たときは「6. 困ったとき」を見てください。

## 3. 起動

```bash
npm start
```

ブラウザで http://localhost:3000 を開き、「Canvaにログインして始める」を押します。初回だけ名前を入力します（履歴に表示されます）。

終了するときはターミナルで `Ctrl + C`。

### お試し（モックモード）

API キーや Canva ログインなしで、画面の流れだけ確かめられます。見本の絵コンテが出ます。

```bash
npm run mock
```

## 4. 使い方

1. **新しく作る**：何の投稿か・届けたい相手・一番伝えたい一言・入れたい情報・ページ数・投稿先を入れ、見た目の方向性を選んで「ラフを作る」。
2. 構成案（ページ割り）ができたあと、方向性ごとに Canva AI が絵コンテを作ります。1案1分ほど。画面は自動で更新されます。
3. 3案を見比べ、使う案の「Canvaで開く」を押す。
4. 動画化メモ（画面の下に手順あり）を見ながら、Canvaでアニメーションと秒数を付けて MP4 で書き出す。
5. **校正**：「校正用にコメント」を押すと、各ページのねらいが Canva のデザインにコメントされます。Canva の「共有」から校正者を招待し、指摘は Canva のコメントで集めます。

その他

- 「作り直す」：その案だけ作り直します（AI クレジット約2%）。
- 「この内容で新しく作る」：過去の入力を下敷きに、新しく作れます。
- 「履歴」：チーム全員のラフを一覧・検索できます。
- 「メモをコピー」「メモを印刷・PDF」：制作依頼や校正に添付できます。

## 5. カスタマイズ

| ファイル | 内容 |
| --- | --- |
| `config/directions.json` | 見た目の方向性（ポップ／信頼感／エモーショナル）。色味・フォント・写真の雰囲気を具体的に書くほど、結果がそろいます。追加もできます（画面では最大3つ選択）。 |
| `config/keywords.json` | 動画化メモの検索キーワードで「使いたい言葉」「避けたい言葉」。団体の活動に合わせて書き換えてください。 |

書き換えたら、アプリを再起動してください。

### 他のPCからも使う場合

`.env` で `HOST=0.0.0.0`、`BASE_URL=http://（このPCのIPアドレス）:3000` にして再起動し、`npm run check-canva` をやり直します。同じネットワーク内のメンバーがブラウザで開けるようになります。インターネットに公開する場合は HTTPS が必要です。

## 6. 困ったとき

| 症状 | 対処 |
| --- | --- |
| `npm run check-canva` で「クライアントの自動登録に対応していません」 | Canva が外部ツールからの接続に申請を求めています。Canva の開発者窓口（https://www.canva.dev/ ）で MCP の利用を申請してください。 |
| ログイン後「ログインの確認に失敗しました」 | ブラウザで開いているアドレスと `.env` の `BASE_URL` が同じか確認（`localhost` と `127.0.0.1` は別扱い）。 |
| 「Canva のログインが切れました」 | 右上の「ログアウト」→ もう一度ログイン。そのあと「作り直す」。 |
| 「Claude API のキーが設定されていません」 | `.env` の `ANTHROPIC_API_KEY` を確認して再起動。 |
| 絵コンテの画像が表示されない | 画像のリンクは約11時間で切れます。ページを開き直すと自動で書き出し直します。 |
| 生成が途中で止まった（アプリを再起動した） | 該当の案で「作り直す」。 |
| Canva の接続を最初からやり直したい | アプリを止めて `data/app.db` を消し、`npm run check-canva` から。※履歴も消えます。 |

## 7. 開発者向け

```
server/
  index.js        HTTP サーバーと API
  canva-oauth.js  Canva MCP へのログイン（OAuth 2.1 / PKCE / 動的クライアント登録）
  mcp-client.js   MCP Streamable HTTP クライアント（JSON / SSE 両対応）
  canva.js        Canva MCP のツール呼び出し（create-design, read-design, export-design, comment-on-design）
  claude.js       Claude API（構成案・動画化メモ）と Canva への指示文
  pipeline.js     生成の流れ（1件ずつ順番に処理）
  mock.js         モックモード
public/           画面（HTML / CSS / JS）
config/           方向性とキーワード
test/             偽物の Canva・Claude を使った通しテスト
```

- テスト：`npm test`（ログイン、トークン自動更新、3案生成、作り直し、検索などを確認）
- Canva への指示文は `server/claude.js` の `buildCanvaBrief`。2026年10月の検証で、この形式で9:16・4ページ・指定どおりのテロップが1回で生成できることを確認済み。
- Canva MCP のツール名は変わることがあります。`create-design` が無いアカウントでは `generate-design` + `create-design-from-candidate` に自動で切り替えます。
